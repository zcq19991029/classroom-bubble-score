# 课堂加分气泡

一个可直接在浏览器中使用的课堂加减分、考勤与操作日志工具。

## 功能

- 3D 透明气泡、拖拽抛出、自然下坠、反弹与碰撞
- 单击 +1，双击 -1，右键自定义分值
- 缺勤、请假、旷课记录
- XLS / XLSX / CSV / TXT 名单导入
- 分数排名、学号查看、分节日志
- 修改单条记录，或清空某一节课的加减分并自动校正总分
- 每节课轮换 4 名值日生，到名单末尾后循环
- JSON 备份导出与导入

## 数据与隐私

数据仅保存在当前浏览器的 `localStorage`，不会上传到 GitHub，也不会与其他使用者共享。换电脑或换浏览器时，请先“导出备份”，再在新设备上“导入备份”。

本公开版只包含“示例同学01～24”等虚构数据，不包含任何真实学生信息。

## 使用

直接访问 GitHub Pages 链接，或下载全部文件后打开 `index.html`。
