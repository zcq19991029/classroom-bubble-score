# 课堂气泡赋分平台

一个面向课堂教学的可视化平时分管理工具。学生以透明 3D 气泡呈现在屏幕中，教师可以通过点击、双击、长按和拖动完成课堂加减分、考勤、作业记录及成绩测算。

无需安装服务器，打开网页即可使用；学生数据与成绩默认保存在当前浏览器中，不会上传到 GitHub。

## 在线体验

**[立即打开课堂气泡赋分平台](https://zcq19991029.github.io/classroom-bubble-score/)**

教师云端版入口：[登录教师云端版](https://zcq19991029.github.io/classroom-bubble-score/cloud.html)。云端版支持邮箱账号登录、跨电脑同步，并由数据库行级权限保证每位老师只能访问自己的数据。

公开版本仅使用虚构的演示学生，不包含任何真实班级、姓名或学号。

## 核心功能

- 透明 3D 肥皂泡效果，支持自然下坠、反弹、碰撞、拖动和抛出。
- 单击学生气泡 `+1`，双击 `-1`，右键可输入任意加减分值。
- 长按气泡快速登记考勤，也可打开完整名单批量勾选。
- 支持缺勤、请假、旷课，并可自行设置对应扣分标准。
- 支持作业加分、扣分、原因记录及历史记录删除。
- 支持姓名、完整学号和学号后两位搜索，快速定位学生气泡。
- 支持 `.xls`、`.xlsx`、`.csv`、`.txt` 考勤名单导入。
- 每次打开先选择“第几节课”，所有加减分和考勤按课节分别记录。
- 每节课按学号顺序轮换 4 名值日生，名单结束后自动循环。
- 后台提供课堂排名、按学号排序、操作日志、考勤记录和综合考核视图。
- 支持修改单条加减分记录，修改后自动校正学生总分。
- 支持清空指定课节的操作日志，并同步撤销该课节产生的分数。
- 支持 JSON 备份导出和恢复，可将记录迁移到其他电脑。

## 综合成绩计算

平台默认按照以下结构计算 100 分制综合成绩：

| 模块 | 模块满分 | 综合成绩占比 |
| --- | ---: | ---: |
| 课堂表现 | 100 | 20% |
| 考勤 | 100 | 10% |
| 作业 | 100 | 10% |
| 期末笔试 | 100 | 60% |

```text
综合成绩 = 课堂表现 × 20% + 考勤 × 10% + 作业 × 10% + 期末笔试 × 60%
```

课堂表现以教师点击气泡形成的原始积分为依据，再按班级排名动态赋分到 `60～100` 分。同分学生采用并列平均名次，避免因排列顺序造成差异。

后台还会实时显示：

- 平时成绩模块分数及折合后的 `40` 分。
- 在当前平时成绩基础上，期末笔试至少需要多少分才能达到综合及格线。
- 输入实际笔试成绩后的最终综合成绩。
- 无法仅靠剩余笔试分数达到及格线时给出提示。

## 快速使用

1. 打开在线页面或本地 `index.html`。
2. 滑动苹果式课节滚轮，选择本次是第几节课。
3. 点击“导入名单”，选择 Excel 考勤表或粘贴学生名单。
4. 单击气泡加分，双击气泡减分；长按登记考勤。
5. 点击“成绩后台”查看排名、日志和综合成绩。
6. 下课后建议点击“导出备份”，将 JSON 文件与网页一起保存。

## 名单格式

Excel 文件会优先识别“学号”和“姓名”列。文本名单支持以下格式，每位学生一行：

```text
20260101,刘同学
20260102,张同学
```

气泡前显示的是学生真实学号的最后两位，而不是导入顺序。搜索支持姓名、完整学号以及学号后两位。

## 数据保存与换电脑

平台使用浏览器 `localStorage` 自动保存数据：

- 刷新网页或关闭浏览器后，在同一电脑、同一浏览器和同一网址下记录仍会保留。
- 换电脑、换浏览器、清理浏览器数据或更换网页地址时，记录不会自动跟随。
- 迁移数据时，请在旧设备点击“导出备份”，再在新设备点击“导入备份”。
- 建议每次下课导出一次备份，避免浏览器数据被误清理。

## 离线使用

下载仓库全部文件，保持 `index.html`、`xlsx.full.min.js` 和 `校徽背景.png` 位于同一文件夹，然后双击 `index.html`。可将整个文件夹复制到 U 盘，在没有网络的教室电脑上使用。

## 隐私说明

- 本项目是纯前端静态网页，没有成绩上传接口和远程数据库。
- 导入的学生名单、课堂分数、考勤、作业和笔试成绩仅保存在使用者浏览器中。
- GitHub 仓库内仅保留模拟数据，禁止提交真实学生信息或包含真实成绩的备份文件。

## 浏览器建议

推荐使用最新版 Chrome、Edge 或其他 Chromium 浏览器。为了确保本地自动保存生效，请不要使用无痕模式，也不要在课程结束前清理网站数据。

## 开源与使用

本项目可用于课堂教学演示和二次修改。若用于正式成绩管理，请结合学校考核制度复核赋分规则，并定期导出备份。
